How this draw is fair

  1. The organizer paid, and this node signed a commitment to the list's fingerprint (SHA-256), its size, the number of winners and the draw time. It went on the node's public log at once.
  2. The winners come from the hash of the first XRP Ledger ledger that closed at or after the draw time. Nobody, this node included, could know that hash when the list was locked.
  3. Anyone can redo the draw. This page does it in your browser: it checks the signatures, reads the ledger from a public XRP Ledger server, and recomputes the winners (rule cappz-draw/v1, written out in the skill).
